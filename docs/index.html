Rules that hold everywhere

Observed across the source videos — steal these regardless of style.

  • Keyword BIG / explanation SMALL — never invert.
  • Hard cuts — dissolves almost never appear.
  • One motion idea per beat — slam, draw, morph, pop — with hard-edged easing.
  • Real imagery = credibility — real photos, logos, UI screenshots in rounded cards.
  • Safe zones @1080×1920 — titles y 170–450 · content within x 90–990 · nothing below y 1570.
  • Rounded media cards ~60px radius, inset ~40px — identical geometry for speaker and graphics so layouts swap without reflow.
