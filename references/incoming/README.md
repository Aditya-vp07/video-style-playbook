# references/incoming — new videos land here

Drop new reference videos (or their links) in this folder for the next
analysis wave. Aditya is expected to send 10–20 more pro-grade videos
via Google Drive link.

## How it works

1. **Add** the file or a `.txt` with the link, named `<source>_<id>.<ext>`
   (e.g. `drive_kinetype01.mp4`, `yt_WcMOCtas1pg.txt`).
2. **Register** it in `INDEX.md` with status `pending`.
3. **Analysis** runs per `techniques/ANALYSIS-PROTOCOL.md`:
   download → frame extraction → spec sheet → fold into styles/recipes/techniques.
4. When folded in, status becomes `analyzed` and the raw file can be
   moved to cold storage (keep `INDEX.md` as the permanent record).
